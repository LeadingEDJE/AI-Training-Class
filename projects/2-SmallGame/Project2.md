# Project 2 - Small Game

In this project we'll create a small game scoped to the scale of an early arcade game, simple board game, or simple windows game like Minesweeper or Solitaire.

The goal is to practice with your prompts and tooling and experiment with writing specifications, seeing what questions your agents ask you, and iterating on an output.

We encourage you to build something fun, put a fun twist on something, don't aim too high, and get something workable, then get AI to adjust it.

Place the game project in a subdirectory inside of this 2-SmallGame directory.

## Game Ideas

- Space Invaders
- Asteroid
- Joust
- Wordle
- Minesweeper
- Othello / Reversi
- Frogger
- Tic Tac Toe
- Checkers
- Dino Runner (Chrome)
- The first level from Super Mario Brothers

## Prompt tips

An ideal prompt specifies:

- What you want to create
- The technologies you want to use
- The way you plan on having the user interacting with it
- How you want it to work (tests, iterative, phases, UI first, etc.)
- Desired style / feeling (for things UX related)
- Important non-functional requirements (error handling, performance, etc)

I strongly encourage you to tell it to ask you questions when it isn't sure, to use plan mode, and to not make your initial request too ambitious for time's sake.

You can paste in images to use as reference or to report bugs to it or things you want to improve.

We also hope you can share some of your results with the class as a whole when you're done.
