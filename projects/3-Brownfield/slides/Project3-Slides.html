02 / 13 Before You Start

Before you start.

5 MIN
  • Pick your repo: yours, or a fallback (eShopOnWeb for .NET, hexo for Node, LEAP for .NET + React) — start the agent inside that folder.
  • Cut a branch: git checkout -b brownfield-lab
  • Own repo → push it: git push -u origin brownfield-lab. Fallback → keep the branch local (or fork first).
  • Fallback prereqs: .NET 8 SDK, or Node 22+. LEAP also needs .NET 10 and Docker.
  • Pick a feature from FEATURES.md (or a real ticket from your own backlog). You will use it twice.

06 / 13 Step 2 · Build & Run It

Get it building and running.

10–20 MIN
  • Same session
  • Prompt 3 — real output only, no summaries
  • Record the working commands in ARCHITECTURE.md
